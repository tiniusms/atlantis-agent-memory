# Meridian Memory Demo

**Scenario:** Meridian Financial
**Team members:** tiniusms

We are building a small demonstration of a customer-facing banking assistant. A Supervisor agent routes each request to a domain agent (Service, Investments, Cards). The comparison runs the same customer conversation twice: once without persistent memory and once with mem9, to show whether the second agent already knows what the customer told the first.

## How to run

Setup and run instructions will be added as the work progresses. The demo cannot be run yet.
